# README figure provenance

The `en/` and `cn/` result PNG/SVG files are unmodified copies of `inner_progress` and `cost_comparison` from the [v10 technical report](../../docs/technical-report/v10/). The underlying `round_aggregates.csv`, `selected_cost.csv`, `generation_population.csv` and `derived_metrics.json` are byte-identical to the [public v6 data](../../docs/technical-report/v6/data/). These presentation copies do not introduce new trials or change the evaluation protocol. Report links and citation metadata refer to v10; v6 remains available as the original evidence release.

The three architecture SVGs in each language copy the [project-page diagrams](../../examples/studio/assets/) with stronger borders and arrows, darker labels and a white background. Nodes, connections and technical content are preserved. They describe the current implementation; the historical report uses a different review protocol.

Section icons in `../readme-icons/` are repository-native SVGs. README headings remain text, with explicit HTML navigation anchors.
