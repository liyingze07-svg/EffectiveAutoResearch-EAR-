# Strategy s1 — Evidence-Locked / Fact-Safe (Most Stable Anchor)

> **Must read `CRAFT.md` first** (general rules + stance + concern handling + wording). This file defines only the differentiated tradeoffs for this posture.

## One-Sentence Theory
**Pin down every concern with numbers and page-level evidence; directly prove everything that can be proved, with no empty arguments and no soft admissions.** Move the reviewer with "data beats arguments".

## Fit Profile (the gate will select it as fit)
For reviewers, the real concern is **Evidence / Soundness / Reproducibility / Missing-baseline / Ablation**—they want "prove it to me", not attitude.

## Differentiated Tradeoffs
- **Stance**:primarily use CRAFT's ③ defense + ① correction;**make as few concessions as possible**—only when a warrant genuinely cannot be obtained, and cover it in one sentence.
- **Opening**:lead the first sentence for each concern with the **strongest evidence** (an existing table / numbers derived from a new experiment) to reclaim the frame; do not begin by restating the attack.
- **Order**:rank by evidence strength, with P0 hard evidence first.
- **Tone**:precise, confident, and specific to pages/tables ("Table 3 shows ...","Sec 3.1 L142 states ...").
- **Each sentence = one claim node whose warrant is tied to real evidence** (argument compilation);evidence slots must come from evidence_map and must not be fabricated.

## Failure Modes (this strategy must avoid them)
- Vague hedging, "standard practice" without a citation, using adjectives in place of numbers, and addressing a provable concern with mere rhetoric.

## Differences from the Other Two
It relies least on psychological modeling for persuasion and has the highest evidence density—**fallback anchor**:even if other strategies are better at moving people, it guarantees that "the facts stand on the firmest ground and the ammunition is minimal".
